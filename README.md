# Internet-Skill-Edu

特別支援学級（中学1〜3年）の生徒が、インターネットやAIの仕組み、AIとの付き合い方、情報モラルを体験しながら学ぶためのWeb教材です。Chromebookのブラウザで動きます。

入り口は `index.html` です。ここから4テーマ×4単元（計16単元）に進めます。

## 設計ルール

- 漢字にはすべてフリガナを付ける
- 操作はタップと選択のみ（文字入力なし）
- 1単元10分以内（体験5〜7分＋ふりかえり2〜3分）
- 見た目は「方眼ノート」：白い方眼紙に青ペンの色、大事な言葉に黄色のマーカー（`.marker`）。中学生向けに落ち着いた明るさにする（絵文字・読み上げ機能は使わない）
- 1画面でやることは1つだけ
- 答えがすぐ分かるヒントは出さない（まちがえたときは考え方のヒントだけ）
- 迷ったときは「ヒントを見る」で、考え方のヒントを1つずつ出せる（試行錯誤を助けるためで、答えは書かない）

## 共通UI（すべての単元で同じ）

どの単元も同じ画面の流れと部品で作ります。単元ごとに見た目を変えないでください。

1. **スタート**：単元番号・タイトル・問いかけ・「スタート」ボタン
2. **体験**：上に指示文のバー、その下に体験の部品、終わると「次へ」
3. **考える**：3問のクイズ。選択肢は3つで、毎回並びが変わる（まちがえても選び直せる）
4. **まとめ**：まとめの一文と、ことば2つ。「もう一度やる」「次の単元へ」

体験と考えるの画面には、指示文のすぐ下に「ヒントを見る」ボタンが出ます。押すたびにヒントが1つずつ増え（2段階）、まちがえるとボタンに黄色のマーカーがついて目が向くようにしています。ヒントは単元のページに書きます。

- 体験のヒント：`activity.hints: ["1つ目", "2つ目"]`（`judge` はカードごとに `hints` を書くと、そのカードだけ差しかえ）
- 考えるのヒント：クイズの各問に `hints: ["1つ目", "2つ目"]`
- 1つ目は「どこを見るか・何を思い出すか」、2つ目は「もう少ししぼった問いかけ」。どちらも答えそのものは書かない

上部バーには常に「一覧」ボタン（入り口へもどる）と、体験・考える・まとめの進み具合が出ます。

| ファイル | 役割 |
| --- | --- |
| `assets/ui.css` | 色・文字・部品のデザイン（ここだけで定義） |
| `assets/engine.js` | 画面の流れ、体験の部品、アイコン |
| `assets/units.js` | 単元の一覧（入り口ページと「次の単元へ」に使う） |
| `units/<単元>/index.html` | 単元の中身（文章とクイズ）だけを書く |

### 体験の部品

| 種類 | 内容 | 使っている単元 |
| --- | --- | --- |
| `relay` | 機械を通る順にタッチして届ける（`free: true` で光らせず、並びもばらばらにする） | A1, A3 |
| `order` | ばらばらに届いたパケットを番号順に組み立て、届かなかったパケットの再送を選ぶ | A2 |
| `spread` | 投稿した写真がコピーされて広がる | A4 |
| `train` | 例をAIに学ばせて、新しい写真を当てさせる | B1, B2 |
| `nextword` | AIの予想から次の言葉を選んで文を作る | B3 |
| `select` | あてはまるものを全部選んで答え合わせ | B4 |
| `judge` | カードを1枚ずつ見て、どうするか選ぶ | C1, C2, D1, D2, D3, D4 |
| `sort` | カードを2つの箱に分ける | C3, C4 |
| `reveal` | タッチして、どう受け取られるかを見る | （現在は未使用） |

### 単元を追加・修正するとき

- 文章のフリガナは `{漢字|かんじ}` と書きます（例：`{送|おく}る`）
- 単元のページにCSSやデザインを書かず、上の部品を使います
- 新しい単元は `assets/units.js` に追加すると、入り口ページに自動で並びます
