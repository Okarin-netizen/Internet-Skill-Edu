# Internet-Skill-Edu

特別支援学級（中学1〜3年）の生徒が、インターネットやAIの仕組み、AIとの付き合い方、情報モラルを体験しながら学ぶためのWeb教材です。Chromebookのブラウザで動きます。

## 設計ルール

- 漢字にはすべてフリガナを付ける
- 操作はタップ・ドラッグ・選択のみ（文字入力なし）
- 1単元10分以内（体験5〜7分＋ふりかえり2〜3分）
- 指示文は音声で読み上げる（「よみあげ」ボタンでオン・オフ）
- 1画面でやることは1つだけ

## 単元

| 単元 | 内容 | 状態 |
| --- | --- | --- |
| [A1 メッセージがとどくまで](units/a1-message/) | スタンプをルーター→サーバー→友だちへタップでリレーし、届く仕組みを体験する | 試作 |

単元一覧の全体（4テーマ×4単元）は計画ドキュメントにまとめています。

## 使い方

各単元は依存のない1枚のHTMLファイルです。GitHub Pagesで公開すると、Chromebookからリンクを開くだけで使えます。

GitHub Pagesの有効化：リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存します。
